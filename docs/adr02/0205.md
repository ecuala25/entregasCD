# Ejercicio 5: Product Backlog con Scrum

## 1. Roles Scrum

 **Product Owner:** Luis, el director - Representa al centro o centros que usarán la plataforma y decide que aporta más valor.

 **Scrum Master:** Un miembro de Tech4Learning - Facilita el proceso Scrum del equipo.

 **Development Team:** El equipo de Tech4Learning - Construye la plataforma.

 **Stakeholder:** Marta, la profesora - Aporta las necesidades del usuario pero no toma decisiones. 

## 2. Historias de usuario.
 
  ### Historia de referencia
  **H0:** Como usuario de la plataforma, quiero iniciar sesión con correo electrónico y contraseña, para acceder a mi contenido personal — 5 puntos (estimación ya realizada)

 ### Material didáctito (Marta)
  **H1:** Como profesor, quiero añadir temas didácticos en formato pdf, vídeo o enlace, para que mis alumnos puedan acceder a el. 
  **H2:** Como alumno, quiero poder acceder al material didáctico desde cualquier dispositivo, para poder estudiar desde el ordenador o el móvil en cualquier lugar. 
  **H3:** Como profesor, quiero poder organizar el contenido por temas o semanas, para que el alumno pueda saber que tema corresponde al momento del curso.

 ### Notificaciones y exámenes (Luís)
 **H4:** Como profsor, quiero formular examenes online con opción multiple y preguntas abiertas, para examinar a mi alumnado sin usar papel. 
 **H5:** Como profesor, quiero que las preguntas de opción multiple se corrijan automáticamente, para ahorrar tiempo de corrección.
 **H6:** Como alumno, quiero recibir una notificación cuando se suba algo a la plataforma, para no tener que entrar constantemente.
 
## 3. Criterios de aceptación
**H1:**
- Dado que el profesor ha seleccionado un archivo PDF de menos de 20 MB, cuando pulsa "Subir material", entonces el archivo queda disponible en la plataforma asociado a su asignatura.
- Dado que el profesor intenta subir un archivo de un formato no soportado, cuando pulsa "Subir material", entonces el sistema muestra un aviso indicando los formatos permitidos y no se sube el archivo.

**H2:**
- Dado que el alumno ha iniciado sesón en el ordenador, cuando accede al apartado de materiales, entonces puede ver el contenido sin problema. 
- Dado que el alumno ha iniciado sesión desde un móvil, cuando entra en el apartado materiales, entonces sigue viendo el contenido pero adaptado a la pantalla del móvil.

**H3:** 
- Dado que el profesor ha subido el "Tema 1", cuando sube material nuevo, entonces puede asignarlo a el.
- Dado que un alumno entra en el apartado de materiales, cuando accede al listado, puede verlo de forma ordenada clasificado por temas o semanas.

**H4:**
- Dado que un profesor está creando un examen, cuando añade una pregunta de tipo "opción múltiple" con varias respuestas, entonces el sistema la guarda marcando cuál es la respuesta correcta.
- Dado que el examen tiene al menos una pregunta y fecha de publicación, cuando se sube, entonces queda visible a partir de esa fecha.

**H5:**
- Dado que un alumno ha completado todas las preguntas de "opción múltiple" de un examen, cuando termina el examen, entonces el sistema calcula automáticamente la nota de esas preguntas.
- Dado que un examen tiene preguntas de tipo "abierta" y de tipo "opción múltiple", cuando se corrige automáticamente, entonces solo corrige las preguntas de tipo "opción múltiple". 

**H6:** 
- Dado que un profesor programa una nueva actividad, cuando se publica, entonces le llega una notificación a todos los alumnos matriculados en la asignatura.
- Dado que un alumno tiene las notificaciones desactivadas, cuando se publica una actividad nueva, entonces no recibe ninguna notificación.
